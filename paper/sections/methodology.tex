\section{Methodology}

\subsection{Baseline Adapter}

The executable baseline is a minimal compatibility layer for publication-era GPTSwarm commit \texttt{1e1e5899d51bde690672417cf92aa4de7b210422}. It retains the upstream candidate-edge order, one Bernoulli logit per potential edge, sequential cycle rejection, majority-vote decision, raw binary-accuracy utility, and Adam update. The selected 1T1A graph has four potential edges: both directed inter-agent edges and one edge from each agent to the decision node. Single-node agents always receive the original MMLU question, matching the upstream MMLU execution path; inter-agent edges therefore primarily control scheduling and which answers reach the decision node.

The adapter adds provider-independent response objects, deterministic seeding, immutable dataset snapshots, and structured JSONL/CSV logging. These additions measure behavior but do not enter the baseline reward. Provider failures, unparseable answers, and graphs without valid decision input are retained and scored incorrect.

\subsection{Budget-Constrained Objective}

The reproduction retains GPTSwarm's accuracy-only edge objective as a baseline. BC-GPTSwarm preserves its edge distribution $D_{\theta}$ but constrains measured resource use. For input $x$, sampled feasible graph $G\sim D_{\theta}$, task utility $U(G,x)$, total-token cost $C(G,x)$, and target $B>0$, the proposed problem is
\begin{align}
    \max_{\theta}\quad & \mathrm{E}_{x,G}[U(G,x)] \\
    \text{subject to}\quad & \mathrm{E}_{x,G}[C(G,x)] \leq B.
\end{align}
Using the normalized constraint $g=\mathrm{E}[C/B-1]\leq0$, its Lagrangian is
\begin{align}
 \mathcal{L}(\theta,\lambda)
 &=\mathrm{E}_{x,G}\!\left[U(G,x)\right. \notag\\
 &\left.\quad-\lambda\left(\frac{C(G,x)}{B}-1\right)\right],\\
 \lambda&\geq0.
\end{align}
Normalization makes the dual scale comparable across budgets; it does not remove the need to predeclare optimizer settings.

The fixed-penalty control instead uses
\begin{equation}
 \max_{\theta}\;\mathrm{E}_{x,G}\!\left[
 U(G,x)-\alpha\frac{C(G,x)}{B_{\mathrm{ref}}}\right],
\end{equation}
where $\alpha$ is fixed before evaluation. Unlike BC-GPTSwarm, this scalarized objective has no mechanism that targets a requested constraint value.

\subsection{Primal--Dual Update}

For $M$ sampled executions, the implemented edge-policy estimate is
\begin{equation}
 \widehat{\nabla_{\theta}\mathcal{L}}=
 \frac{1}{M}\sum_{i=1}^{M}
 \left[A_i-\lambda\left(\frac{C_i}{B}-1\right)\right]
 \nabla_{\theta}\log p_{\theta}(G_i),
\end{equation}
where $A_i$ is a centered task-utility advantage. The dual variable follows projected dual descent, equivalently increasing its penalty when the observed constraint is violated:
\begin{equation}
 \lambda\leftarrow\left[\lambda+\eta_{\lambda}
 \left(\frac{1}{M}\sum_{i=1}^{M}\frac{C_i}{B}-1\right)\right]_{+}.
\end{equation}
The primary cost $C$ is the sum of reported input and output tokens across model calls. Dollar cost and latency are recorded but excluded from the initial constraint to keep the intervention identifiable.

\subsection{Feasible Conditional Policy}

A zero-call or disconnected graph can satisfy a token target without solving the task, so BC-GPTSwarm conditions the training policy on event $F$: at least one agent has an edge to the decision node. Let $E_D$ be those candidate edges. Because the decision node is a sink, these edges cannot introduce cycles, and
\begin{align}
 q_{\theta}=P_{\theta}(F)
 &=1-\prod_{e\in E_D}(1-p_e),\\
 \log p_{\theta}(G\mid F)
 &=\log p_{\theta}(G)-\log q_{\theta}.
\end{align}
Training uses rejection sampling and the corrected conditional log probability above. Omitting $\log q_{\theta}$ would sample the conditional distribution but use the wrong score-function gradient. Held-out evaluation draws one feasible graph per example from the frozen conditional policy with a recorded seed. A thresholded feasible export is also available, but it is not used to estimate the expected constraint.

\subsection{Optimization Procedure}

For each target budget and seed, the proposed procedure is:
\begin{enumerate}
    \item calibrate a valid cost floor and freeze $B$, model settings, prompts, and candidate edges;
    \item sample $M$ feasible DAGs from $D_{\theta}$ for the current optimization batch;
    \item execute every sampled graph, recording task utility and per-call token metadata;
    \item compute the centered utility advantage and normalized budget violation;
    \item update edge logits by the primal policy-gradient estimate and update $\lambda$ by projected dual descent; and
    \item after the fixed optimization allowance, evaluate the frozen edge policy on held-out examples.
\end{enumerate}
The implementation exposes the primal and dual learning rates, batch size, budget, initial dual value, centered-utility switch, feasibility rule, and random seed in configuration. Algorithm~1 summarizes the executable update.

\fbox{\begin{minipage}{0.91\columnwidth}
\small
\textbf{Algorithm 1: BC-GPTSwarm training}\par
\textbf{Input:} policy $D_{\theta}$, budget $B$, rates $\eta_{\theta},\eta_{\lambda}$\par
1. Measure the valid direct-path cost floor; reject $B$ below it.\par
2. For each iteration, draw $M$ graphs from $D_{\theta}(\cdot\mid F)$.\par
3. Execute each graph and record utility $U_i$ and tokens $C_i$.\par
4. Set $A_i=U_i-\bar U$ and $s_i=A_i-\lambda(C_i/B-1)$.\par
5. Apply Adam to $-M^{-1}\sum_i s_i\log p_{\theta}(G_i\mid F)$.\par
6. Set $\lambda\leftarrow[\lambda+\eta_{\lambda}(\bar C/B-1)]_+$.\par
7. Evaluate seeded draws from the frozen feasible policy.
\end{minipage}}
\end{center}

With $E$ candidate edges, feasibility probability $q_{\theta}$, batch size $M$, and $I$ iterations, the current simple cycle checks give expected sampling cost $O(E^2/q_{\theta})$ per graph. Total optimization cost is $O(IM(E^2/q_{\theta}+T_{\mathrm{exec}}))$, where language-model execution $T_{\mathrm{exec}}$ dominates in practice; learned-parameter memory is $O(E)$.

\subsection{Feasibility and Fairness}

A disconnected or zero-call graph is not a valid budget solution. The runner measures the mean cost of a valid truthful direct-answer path on the optimization split and rejects lower budgets. Every proposed-method sample retains an input-to-decision path. Phase 6 will apply the same feasibility rule, candidate edges, and optimization-call allowance to accuracy-only, fixed-penalty, and constrained methods. The implementation is complete, but research claims remain pending controlled experiments.
