\section{Conclusion}

This work-in-progress implements a minimal reproduction of GPTSwarm's MMLU edge optimizer and BC-GPTSwarm, a primal--dual extension for maximizing expected task utility subject to an expected token budget. In the reduced local baseline, optimized and random graphs both average 0.250 accuracy; optimized graphs use fewer tokens than full graphs but do not establish an accuracy advantage. Learned baseline policies consistently strengthen truthful decision edges, while adversarial suppression remains seed-dependent. Feasible-policy conditioning, corrected conditional gradients, projected dual updates, and complete resource telemetry now pass offline and deterministic smoke validation. The planned Phase 6 evaluation will separate resource control from task quality using budget error and compliance alongside accuracy, tokens, cost, and graph structure. No real-model proposed-method result is claimed. Results pending proposed-method experiment.
