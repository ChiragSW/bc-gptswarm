\section{Conclusion}

This work-in-progress implements a minimal reproduction of GPTSwarm's MMLU edge optimizer and proposes BC-GPTSwarm, a primal--dual extension for maximizing expected task utility subject to an expected token budget. In the reduced local baseline, optimized and random graphs both average 0.250 accuracy; optimized graphs use fewer tokens than full graphs but do not establish an accuracy advantage. Learned policies consistently strengthen truthful decision edges, while adversarial suppression remains seed-dependent. The planned proposed-method evaluation will separate resource control from task quality using budget error and compliance alongside accuracy, tokens, cost, and graph structure. BC-GPTSwarm has not yet been implemented or evaluated. Results pending proposed-method experiment.
