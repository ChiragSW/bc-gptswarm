\section{Conclusion}

This work-in-progress defines a minimal reproduction of GPTSwarm's MMLU edge optimizer and proposes BC-GPTSwarm, a primal--dual extension for maximizing expected task utility subject to an expected token budget. The planned evaluation separates resource control from task quality by measuring budget error and compliance alongside accuracy, tokens, cost, latency, and graph structure. It includes accuracy-only and fixed-penalty controls so any benefit can be attributed to the constraint mechanism rather than resource measurement alone. Implementation and experiments have not begun. Results pending experiment.
