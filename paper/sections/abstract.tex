Language-agent systems can be expressed as computational graphs whose edges control communication and computation. GPTSwarm makes these edges optimizable, but its reported objective maximizes task utility without an explicit resource constraint. We implement BC-GPTSwarm, a primal--dual policy-gradient extension that maximizes expected utility subject to an expected token budget. It adds feasible-policy conditioning, corrected conditional gradients, token telemetry, and a learned non-negative Lagrange multiplier while retaining GPTSwarm's graph and node routines. We evaluate a reduced adversarial MMLU setting with a 1T1A graph, a local 0.5B model, 24 held-out questions, and three seeds. The original accuracy-only baseline averages 0.250 accuracy and 251.1 tokens per question. Middle-budget BC-GPTSwarm averages 0.236 accuracy and 236.7 tokens, a 5.8\% token reduction, but exceeds its target by 4.0\%. The low target is missed by 28.8\%; only the high target has aggregate slack. A 2T2A ablation reaches 0.278 accuracy but uses 419.5 tokens. Wide seed variation and paired outcomes do not support an accuracy improvement. The method is mechanically valid, but tight-budget convergence is not established under the fixed 12-iteration allowance.
