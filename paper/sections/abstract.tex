Language-agent systems can be expressed as computational graphs in which nodes perform model or tool operations and edges carry information. GPTSwarm makes graph edges and node prompts optimizable, but its reported edge objective maximizes task utility without an explicit resource constraint. We propose BC-GPTSwarm, a small extension that uses a primal--dual policy-gradient update to maximize expected utility subject to an expected token budget. The method preserves GPTSwarm's graph, node routines, feasible-DAG sampler, and REINFORCE formulation while adding token telemetry and a learned non-negative Lagrange multiplier. We first reproduce the adversarial MMLU edge setting with a 1T1A graph and a small local model. Across three seeds and 24 validation questions, accuracy-only optimized and random graphs both average 0.250 accuracy, while full and direct graphs average 0.264 and 0.167. Optimized graphs use 6,027 tokens on average versus 7,279 for full graphs, but do not improve over random graphs. The proposed constrained method has not been evaluated.
