Language-agent systems can be expressed as computational graphs in which nodes perform model or tool operations and edges carry information. GPTSwarm makes graph edges and node prompts optimizable, but its reported edge objective maximizes task utility without an explicit resource constraint. We propose BC-GPTSwarm, a small extension that uses a primal--dual policy-gradient update to maximize expected utility subject to an expected token budget. The method preserves GPTSwarm's graph, node routines, feasible-DAG sampler, and REINFORCE formulation while adding token telemetry and a learned non-negative Lagrange multiplier. The planned study reproduces the adversarial MMLU edge setting and compares direct, full, random, accuracy-only, fixed-penalty, and budget-constrained graphs under matched conditions. Primary outcomes are accuracy, total tokens, normalized budget violation, and compliance rate; cost, latency, and graph size are secondary outcomes. Results pending experiment.
