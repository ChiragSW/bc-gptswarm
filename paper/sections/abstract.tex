Language-agent systems can be expressed as computational graphs in which nodes perform model or tool operations and edges carry information. GPTSwarm makes these graph edges and node prompts optimizable, but its reported objective does not directly optimize resource use. This work-in-progress study first reproduces GPTSwarm's adversarial MMLU edge-optimization setting under a controlled, current model configuration. A small efficiency-oriented extension will be selected after a structured gap analysis. The planned evaluation will compare task accuracy, token usage, cost, latency, and graph structure under matched conditions. Results pending experiment.
